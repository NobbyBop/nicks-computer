Nick's Computer

Hello, welcome to my computer. Here you can find my writings on things that interest technically, projects I've worked on, code snippets, and more. I'm writing all the code for this project myself by hand. While not "creative" in the traditional sense, programming is an important expression of myself and that is what I want to come across.

Experiment No. 1

For my first entry on this website I wanted to create a welcome page that displays its own source code. I was inspired to write my own tool for this because I had been watching this video where he writes a custom parser for his own personal records. It looked fun to make an ad-hoc Python tool for something, so as an introduction to this project, I made one too.

It does a simple encoding of <, >, ", and &. However, since I was planning on injecting the encoded text back into this very file, I couldn't also include the code block. (Encode the HTML, update the HTML with the encoding, encode the new HTML, and so on.) So, I also checked for the code block in my Python script and omitted it.

As a second step, I decided it would be nice if the script could

  1. Encode and save all of this HTML file except the code blocks.
  2. Remember where the code block begins in the original file.
  4. Inject the encoded string back into the HTML that it is an encoding of.
